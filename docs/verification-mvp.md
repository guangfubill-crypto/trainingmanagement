## 浏览器验收

1. 登录错误提示；登录成功进入课程；刷新恢复身份；退出后受保护页面跳回登录。
2. 管理员新增课程、必填校验、详情、编辑、搜索、取消删除、确认删除和空状态。
3. 管理员新增学员、重复学号错误、详情、编辑和删除。
4. 管理员新增用户、编辑用户名、详情、密码重置；另一个浏览器上下文的原会话失效；新密码可登录；删除后再次失效。
5. 11 条记录跨页查询；普通用户查看详情，无写入口；直接访问用户页面被重定向，用户 API 与课程写 API 返回 403。
6. 失效会话跳转、网络错误与重试、390px 手机布局无页面横向溢出。

已查看桌面登录、课程列表及手机截图。发现手机固定操作列遮挡内容后，改为表格横向滚动并提供提示；相关分页与手机场景再次验证。浏览器验收使用独立临时数据库与 8010/5174 端口，未写入本地业务数据库。
