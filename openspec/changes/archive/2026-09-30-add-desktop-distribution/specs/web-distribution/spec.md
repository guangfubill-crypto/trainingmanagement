## Purpose
继续为需要通过浏览器访问的使用者提供原有 Web 服务能力，并提供明确可重复的服务器打包与持久化方式，让桌面版的新增不会改变现有业务和权限契约。

## ADDED Requirements
### Requirement: Web 版本保持可用
系统 SHALL 保留原有开发启动、管理员 CLI、API、角色权限和数据库配置；Web 模式不得开放桌面首次管理员配置接口。
#### Scenario: Web 回归
- **WHEN** 使用 Web 入口启动
- **THEN** 原有登录、CRUD 和权限测试继续通过，桌面配置返回 404

### Requirement: 生产页面与持久化部署
系统 SHALL 提供生产前端和 API 同源托管，以及容器部署文件和持久数据卷说明；前端深层路由能刷新，未知 API 返回 404，静态资源不能越界访问。
#### Scenario: 页面刷新
- **WHEN** 访问生产页面中的 /courses 或 /students
- **THEN** 返回前端页面并由既有登录守卫处理权限
#### Scenario: 数据独立
- **WHEN** 云端实例重建或本地桌面启动
- **THEN** 云端持久卷保留数据，桌面不会自动读取、覆盖或同步云端数据库
