## ADDED Requirements

### Requirement: 静态在线演示
系统 SHALL 提供无需后端的独立静态构建，复用现有课程、学员和用户管理页面，使用明确标注的虚构数据，不能向正式 API 发送请求。
#### Scenario: 打开演示
- **WHEN** 访客从 GitHub Pages 打开页面
- **THEN** 显示演示说明及管理员/普通用户体验入口，无需输入真实凭据

### Requirement: 可操作与重置
演示 SHALL 支持管理员搜索、分页、详情、增删改，编号唯一、正整数课时、最后管理员及当前账号保护；只读角色只能查看课程和学员。业务修改在当前浏览器保存，重置需确认。不保存输入的密码，不将演示角色模拟当作真实认证。
#### Scenario: 完整体验
- **WHEN** 管理员创建课程后刷新，再退出并以普通用户进入
- **THEN** 新课程仍可见，普通用户不能修改或访问用户管理
#### Scenario: 恢复数据
- **WHEN** 确认重置演示数据
- **THEN** 恢复种子数据并返回角色选择页，其他浏览器数据不受影响

### Requirement: 发布与正式版本隔离
系统 SHALL 支持仓库子路径、深链接刷新及自动发布；正式 Web 和桌面构建继续使用真实后端，不包含演示 adapter。
#### Scenario: 深链接
- **WHEN** 访问或刷新 /trainingmanagement/#/students
- **THEN** 静态资源正常加载，经演示角色检查后显示正确页面
